# План реструктуризации: backend + frontend в одном репозитории

## Цель
Разделить monolith-проект на два отдельных приложения для Amvera:
- **backend/** — Telegram бот + FastAPI (порт 8000, PostgreSQL)
- **frontend/** — React MiniApp + Nginx (порт 80)

## Структура после реструктуризации
```
OnlineZap/
├── backend/                    # Backend приложение
│   ├── main.py                 # Бот + FastAPI
│   ├── webapp/                 # FastAPI routes
│   ├── handlers/               # Telegram handlers
│   ├── config/                 # settings.py
│   ├── database/               # SQLAlchemy
│   ├── services/               # Бизнес-логика
│   ├── middlewares/
│   ├── exceptions/
│   ├── filters/
│   ├── keyboards/
│   ├── utils/
│   ├── requirements.txt
│   ├── Dockerfile
│   ├── amvera.yaml
│   └── credentials.json        # Google Sheets (MVP)
│
├── frontend/                   # Frontend приложение
│   ├── app/                    # React проект (Vite)
│   ├── Dockerfile
│   ├── nginx.conf
│   └── amvera.yaml
│
├── .gitignore                  # Обновить
└── README.md                   # Обновить
```

## Шаг 1: Создать backend/
**Действия:**
1. Создать папку `backend/`
2. Переместить файлы:
   - `main.py` → `backend/`
   - `webapp/` → `backend/`
   - `handlers/` → `backend/`
   - `config/` → `backend/`
   - `database/` → `backend/`
   - `services/` → `backend/`
   - `middlewares/` → `backend/`
   - `exceptions/` → `backend/`
   - `filters/` → `backend/`
   - `keyboards/` → `backend/`
   - `utils/` → `backend/`
   - `requirements.txt` → `backend/`
3. Скопировать `credentials.json` в `backend/credentials.json`

**Изменения в коде:**
- `config/settings.py` — обновить путь к `.env`:
  ```python
  _env_path = _project_root / ".env"  # было .env_backup
  ```
- Обновить относительные импорты в `main.py` (убедиться что работают)

## Шаг 2: Создать Dockerfile для backend/
```dockerfile
FROM python:3.12-slim

RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc libpq-dev curl && rm -rf /var/lib/apt/lists/*

WORKDIR /app
COPY requirements.txt .
RUN python -m venv /opt/venv
ENV PATH="/opt/venv/bin:$PATH"
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000
HEALTHCHECK --interval=30s --timeout=10s --start-period=40s --retries=3 \
    CMD curl -f http://localhost:8000/api/health || exit 1

CMD ["/opt/venv/bin/python3", "main.py"]
```

## Шаг 3: Создать amvera.yaml для backend/
```yaml
meta:
  appTitle: "OnlineZap Backend"
  toolchain: docker

services:
  backendlonlinezap:
    image: backend
    build:
      context: .
      dockerfile: Dockerfile
    containerPort: 8000
    persistence:
      - mount: /app/Data
        name: backend-data
    args: []

postgresql:
  - name: onlinezap-db
    version: "16"
    disks:
      etalon:
        size: 1024
```

## Шаг 4: Создать frontend/
**Действия:**
1. Создать папку `frontend/`
2. Переместить:
   - `app/` → `frontend/app/`
   - `nginx.conf` → `frontend/nginx.conf`
3. Обновить `app/vite.config.ts` — убрать режим backend, оставить только frontend

## Шаг 5: Создать Dockerfile для frontend/
```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY app/package.json ./
RUN npm install
COPY app/ ./
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## Шаг 6: Обновить nginx.conf
```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://amvera-backonlinezap-run-<user>:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```
**Примечание:** `<user>` заменить на реальный username после деплоя backend.

## Шаг 7: Создать amvera.yaml для frontend/
```yaml

services:
```

## Шаг 8: Обновить vite.config.ts
```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'

export default defineConfig({
  plugins: [react()],
  base: '/',
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
  build: {
    outDir: 'dist',
    emptyOutDir: true,
    rollupOptions: {
      output: {
        manualChunks: {
          vendor: ['react', 'react-dom'],
        },
      },
    },
  },
  server: {
    port: 3000,
    strictPort: true,
  },
})
```

## Шаг 9: Обновить app/package.json
Убрать скрипты `build:backend` и `build:frontend`, оставить только `build`.

## Шаг 10: Обновить .gitignore
```
backend/credentials.json
*.log
.env
```

## Шаг 11: Деплой на Amvera
1. **Backend app:**
   - Загрузить `backend/amvera.yaml`
   - Dockerfile: `Dockerfile`
   - Порт: `8000`
   - Environment variables: `BOT_TOKEN`, `ADMIN_IDS_CSV`, `DATABASE_URL`, `GOOGLE_SHEET_ID`, `MINIAPP_URL`
   - Загрузить `credentials.json` как файл

2. **Frontend app:**
   - Загрузить `frontend/amvera.yaml`
   - Dockerfile: `Dockerfile`
   - Порт: `80`
   - Обновить `nginx.conf` с реальным доменом backend

3. **Получить домены:**
   - Backend: `backonlinezap.<user>.amvera.io`
   - Frontend: `frontonlinezap.<user>.amvera.io`

4. **Обновить:**
   - `nginx.conf` — заменить `<user>` на реальный
   - `MINIAPP_URL` = `https://frontonlinezap.<user>.amvera.io/app`

## Ключевые точки
- Каждый проект — отдельный Docker build
- Каждый проект — отдельный `amvera.yaml`
- Frontend общается с backend через внутренний URL Amvera
- credentials.json хранится в backend/ (MVP)
- Бот работает только на Amvera (VPS остановить)
