# План миграции OnlineZap на Amvera с PostgreSQL

## Цель
Перенести проект OnlineZap на платформу Amvera с использованием PostgreSQL и разделением на два приложения:
1. **Backend** — Telegram бот + FastAPI API (порт 8000)
2. **Frontend** — MiniApp (статические файлы React)
3. **Database** — Managed PostgreSQL на Amvera

## Критические моменты

### 1. PostgreSQL Connection
- Использовать `postgresql+asyncpg://user:password@host:5432/dbname`
- Настроить connection pooling (max_connections)
- Инициализация таблиц при старте (`init_db()`)

### 2. Telegram Bot + FastAPI в одном процессе
- Bot polling и FastAPI запускаются параллельно
- Общий event loop (asyncio)
- Общая сессия БД

### 3. CORS Configuration
- Backend должен разрешать запросы от frontend домена
- Amvera генерирует домены вида: `app-name.project.amvera.site`

### 4. Static Files
- Frontend app serves static files напрямую
- Backend app также может serve MiniApp файлы (альтернатива)

### 5. Environment Variables
- Все секреты через Amvera dashboard
- `BOT_TOKEN`, `GOOGLE_SHEET_ID`, `DATABASE_URL`
- `credentials.json` как volume/secret

## Риски и решения

| Риск | Решение |
|------|---------|
| Telegram API заблокирован | Использовать proxy или Webhook mode |
| PostgreSQL connection issues | Настроить pooling и retries |
| CORS ошибки | Настроить allow_origins для Amvera доменов |
| Google Sheets credentials | Mount credentials.json как secret |
| Memory limits on Amvera | Настроить resources в amvera.yml |
